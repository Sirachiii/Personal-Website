Built with React, TypeScript and React Flow.

Each tier carries four times the power of the last.

Inspirations

Things that shaped how I build.

明快

The MingKwai typewriter

In the 1940s Lin Yutang built a Chinese typewriter with seventy-two keys. You press two keys to describe the top and bottom of a character, and a small window called the magic eye shows the candidates so you can pick one.

It never pretended Chinese was simple. It broke a huge system into steps you can see and follow, which is how I want everything I make to work.
